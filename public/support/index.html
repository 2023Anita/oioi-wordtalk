FAQ

Do I need an API key? 需要 API Key 吗？ No. Demo mode works offline with no key and covers every feature (stories, chat, logic training). To get freshly generated content, add your own key from a provider you choose (BYOK). 不需要；演示模式离线可用。

Is this an official IELTS product? 是官方雅思产品吗？ No. OiOi WordTalk is an independent English-learning tool and is not affiliated with or endorsed by IELTS (British Council, IDP: IELTS Australia, Cambridge University Press & Assessment).

Is Dr. Anita giving medical advice? Dr. Anita 提供医疗建议吗？ No. Medical scenes are role-play for language practice only, not medical advice. 仅供语言练习，非医疗建议。
